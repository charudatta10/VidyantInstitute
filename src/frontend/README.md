# Frontend & UX Layer

This module handles the frontend and user experience for SageEduMint.
It provides the user interface for interacting with the decentralized university.

## How to View the Basic Frontend

To view the basic HTML, CSS, and JavaScript implementation:

1.  Navigate to the `src/frontend/` directory in your file system.
2.  Open the `index.html` file in your web browser (e.g., by double-clicking it).

You should see a basic web page displaying the welcome message and an overview of the core modules. Clicking on a module item will trigger a simple alert.
